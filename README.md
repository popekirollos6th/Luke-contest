مسابقة إنجيل لوقا — الأجزاء 1 إلى 3

الملفات:
- index.html: صفحة المسابقة، 1–6 و7–12 و13–18. الجزء الأول يظل مقفولًا كما في النسخة الحالية، والجزء الثاني محدد افتراضيًا، ويمكن اختيار الجزء الثالث.
- admin.html: لوحة النتائج مع فلتر للأجزاء الثلاثة.
- supabase-config.js: إعدادات الاتصال الحالية.
- supabase_part3_migration.sql: شغّليه مرة واحدة في Supabase SQL Editor بعد تحديث الموقع أو قبله؛ يحافظ على النتائج القديمة ويتيح part=3.

خطوات التحديث:
1) في Supabase SQL Editor شغّل كامل ملف supabase_part3_migration.sql مرة واحدة.
2) في GitHub ارفع واستبدل index.html وadmin.html وsupabase-config.js من هذه الحزمة، ثم Commit changes.
3) افتح الموقع في نافذة خاصة واختبر الجزء الثالث باسم تجريبي لم يستخدمه أحد في الجزء الثالث.
4) لا تشغّل supabase_setup.sql أو supabase_part2_migration.sql مرة أخرى.

كل محاولة تخزن رقم الجزء بشكل مستقل. بنك الأسئلة للجزء الثالث يغطي الإصحاحات 13–18، مع أسئلة اختيار متعدد وصح/غلط وأكمل. ترتيب الاختيارات يُخلط لكل سؤال مع تحديث مفتاح الإجابة الصحيح.
