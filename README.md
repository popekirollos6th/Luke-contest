مسابقة إنجيل لوقا — الجزء الرابع (الإصحاحات 19–24)

محتويات الحزمة:
- index.html: واجهة المسابقة. الأجزاء 1 و2 و3 مقفولة، والجزء الرابع متاح.
- admin.html: لوحة النتائج مع فلتر للأجزاء الأربعة.
- supabase-config.js: إعدادات الاتصال العامة الحالية.
- supabase_part4_migration.sql: ترقية قاعدة البيانات للسماح بالجزء الرابع دون حذف أي نتائج.

مهم قبل النشر:
1) لا تشغّلي ملف supabase_part3_migration.sql القديم مرة أخرى؛ لأنه كان يقصر الأجزاء على 1 و2 و3.
2) إذا كنتِ قد شغّلتِ بالفعل كود SQL الذي يسمح بالجزء الرابع ويعدّل reserve_quiz_attempt، فلا تحتاجين إلى تشغيل migration مرة أخرى. وإلا شغّلي supabase_part4_migration.sql مرة واحدة في Supabase SQL Editor.
3) ارفعي واستبدلي الملفات index.html وadmin.html وsupabase-config.js في GitHub Pages. لا تحذفي أي صفوف أو جداول من Supabase.
4) ارفعي ملفات الحزمة إلى نفس مجلد الموقع، مع إبقاء أسماء الملفات كما هي.
5) افتحي الموقع في نافذة خاصة أو اعملي تحديثًا قويًا للصفحة.

المسابقة:
- الجزء الرابع يغطي الإصحاحات 19 إلى 24.
- 36 سؤالًا في بنك الجزء الرابع، ويُختار 20 سؤالًا عشوائيًا في كل محاولة.
- 20 ثانية لكل سؤال.
- ترتيب الاختيارات يتغير عشوائيًا، ومواقع الإجابات الصحيحة موزعة في بنك الأسئلة.
- يتم حجز المحاولة في Supabase قبل بدء الأسئلة، ولا تبدأ المسابقة إذا فشل الحجز.
- بعد النهاية تنتظر الصفحة تأكيد حفظ النتيجة وتعرض حالة الحفظ.

الحفاظ على البيانات:
- لا يوجد في ملفات الترقية أي أمر DELETE أو TRUNCATE.
- لا تعيدي تشغيل إعداد قاعدة البيانات الأساسي أو ملفات migrations القديمة للأجزاء السابقة.
